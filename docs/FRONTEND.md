# Frontend Andina

La implementación actual se describe en [PATRONES_REFERENCIA.md](PATRONES_REFERENCIA.md).

Se mantienen los 18 módulos, los responsables indicados por el usuario, la conexión directa a localhost:8080 y PostgreSQL local. Los proyectos se ejecutan por separado: backend en IntelliJ y frontend en Visual Studio Code.

Los componentes y servicios de cada entidad son explícitos, siguiendo los archivos aportados. Materiales, Materiales por curso y Convenios conservan las pantallas de Edisson. Los cuatro módulos excluidos no se incorporan.

La estructura y los datos SQL de demostración están en [database/README.md](../database/README.md).
